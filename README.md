# StudyFlow — Student Planner

StudyFlow is a free, simple student planner for organizing assignments, deadlines, and study progress.

## Features

- Add assignments with optional deadlines and subjects.
- Mark assignments as completed.
- Filter all, open, and completed assignments.
- Delete individual assignments or remove all completed ones.
- View a quick summary of your progress.
- Save tasks locally in your browser using `localStorage`.
- Responsive layout for desktop and mobile.
- No installation, account, or external libraries required.

## Getting started

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add your first assignment.

Your tasks stay in the browser where you use StudyFlow. They are not automatically synchronized across devices.

## Project files

- `index.html` — page structure and content.
- `style.css` — visual styling and responsive layout.
- `script.js` — task management, filtering, and local storage.

## Privacy

StudyFlow does not send assignments or deadlines to a server. Data is stored in your browser's local storage. If you clear your browser data, your saved tasks may be deleted.
